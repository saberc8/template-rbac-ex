# user

## 目的
提供用户体系与用户管理能力，包括查询、创建、更新、导入导出与角色分配等。

## 模块概述
- **职责:** 用户 CRUD、密码重置/修改、用户与角色关联维护、导入导出
- **状态:** ✅稳定
- **最后更新:** 2026-01-11

## 规范

### 需求: 管理员维护系统用户
**模块:** user
管理员可对用户进行列表查询与增删改查，并可分配角色。

#### 场景: 修改用户密码
调用 `PATCH /system/user/:id/password`。
- 预期更新用户密码并记录审计日志

#### 场景: 分配用户角色
调用 `PATCH /system/user/:id/role`。
- 预期更新 `sys_user_role` 关联关系

## API接口
- 主要前缀：`/system/user*`

## 数据模型
- `sys_user`
- `sys_user_role`
- 关联：`sys_role`

## 依赖
- RBAC 模块（角色定义与授权关系）
