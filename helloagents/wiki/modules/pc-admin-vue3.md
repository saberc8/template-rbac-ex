# pc-admin-vue3

## 目的
提供基于 Vue3 的管理端 UI，用于登录、权限路由加载、系统管理与监控操作。

## 模块概述
- **职责:** 页面与路由、状态管理、与后端 API 交互、构建与发布
- **状态:** ✅稳定
- **最后更新:** 2026-01-11

## 规范

### 需求: 管理端对接后端认证与系统管理接口
**模块:** pc-admin-vue3
管理端通过 Bearer Token 与后端交互，加载用户信息与路由菜单，并提供系统管理功能入口。

#### 场景: 用户登录后加载权限路由
登录成功后调用后端接口获取用户信息与路由。
- 预期返回用户信息与可访问路由
- 未授权时前端应引导重新登录

## API接口
对接后端接口（以 `helloagents/wiki/api.md` 与 Swagger 为准），主要前缀包括：
- `/auth/*`、`/system/*`、`/monitor/*`、`/common/*`

## 数据模型
前端无直接数据库表；相关展示字段以 API 返回为准。

## 依赖
- 后端服务 `backend-go`
